Perguntas frequentes.

Não encontrou sua resposta? Chame no WhatsApp.

O que é o Dev+ Control?

É um cliente desktop para Windows que permite conectar-se a servidores SoulFire compatíveis e gerenciar instâncias, bots e scripts.

O aplicativo hospeda os bots?

Não. O Dev+ Control roda no seu PC e é usado para se conectar a um servidor. Ele não é um serviço de hospedagem na nuvem.

Como faço para baixar?

Use o botão de download desta página. O instalador para Windows também fica disponível na página de releases do GitHub.

Como compro e ativo a licença?

Fale pelo WhatsApp para combinar o pagamento. Após a confirmação, enviamos sua chave, que você informa no aplicativo. O período mensal começa na primeira ativação.

O pagamento é feito pelo site?

Não. A compra é combinada diretamente pelo WhatsApp; o site não processa pagamento nem ativa licença automaticamente.

Preciso de um servidor?

Sim. Você precisa de uma instância SoulFire local ou de acesso a um servidor remoto compatível para usar as funções de conexão.
