Dúvidas comuns.

O que preciso para usar o Dev+ Control?

Um computador Windows de 64 bits e acesso a um servidor SoulFire compatível, local ou remoto.

O download inclui um servidor?

O Dev+ Control é o cliente desktop. Você pode escolher a opção de servidor integrado quando disponível ou conectar-se a um servidor remoto compatível.

Preciso de uma licença?

O acesso aos recursos comerciais do Dev+ Control requer uma licença Dev+ ativa. A ativação é feita no próprio aplicativo.

Como compro uma licença mensal?

Chame pelo WhatsApp no botão desta página para combinar o pagamento. Após a confirmação, você recebe a chave de ativação. O período começa na primeira ativação.

Onde encontro novas versões?

Baixe a versão mais recente na página de downloads. Para consultar o histórico e outros instaladores, acesse a página de releases do GitHub.
